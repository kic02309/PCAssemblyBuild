# 조립QC 시험 묶음

실제로 문제가 됐던 사례를 모아 둔 시험입니다. 코드를 고칠 때마다 배포 전에 돌려서, 고친 것 때문에 다른 데가 깨지지 않았는지 확인합니다.

    python3 tests/qc1/run.py

- `cases.json` : 사례 (입력 → 나와야 하는 값). 새 오류를 고치면 그 사례를 한 줄 더 넣습니다.
- `parts.json` : 사례에 쓰는 제품코드 목록 (서버 qc_part 에서 필요한 것만).
- 화면 주소에 `?qtest=1` 이 있을 때만 시험용 함수가 열립니다 (평소 화면에는 영향 없음).

v33.66부터 앱이 서버 기록에 주문서 글자(`doc-txt`)와 CMOS 일치 글자(`cm-txt`)를 남깁니다. 이 실제 글자로 사례를 계속 늘립니다.
이상한 값은 `sanity` 기록으로 남습니다 (예: 메모리 용량 ÷ 개수가 말이 안 될 때 → 개수 확인을 빼고 기록).
